The Tier 2 model serves as a proxy for deep verification. This introduces an impersonation risk: if the trained Tier 2 model is wrong on novel network flows (which it was not trained on), the pseudo-labels it generates may be noisy or incorrect. The CIC-IDS dataset ground-truth labels (column 'Label') are used ONLY in the evaluation function to compute reported accuracy — they are never fed back to Tier 1 during the adaptation loop.
